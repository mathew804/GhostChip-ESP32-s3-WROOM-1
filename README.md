# GhostChipUI — GitHub Edition

A static, responsive GhostChip ESP32-S3 dashboard inspired by the reference UI you provided.

## Included
- Animated CSS 3D-style device
- Interactive device page
- Your supplied front/back board photos
- Hardware/pin learning map
- Safe DuckyScript-style simulator
- Wi-Fi/BLE learning lab simulations
- microSD/storage UI
- ESP32-S3 learning roadmap
- Mobile responsive layout

## GitHub Pages
Upload the files in this folder to the root of a GitHub repository. Then go to **Settings → Pages**, select the main branch and root folder, and save.

Open `index.html` locally to test without a server.

## Safety
This version intentionally keeps network and USB security features as learning/simulation interfaces. Use physical testing only on systems and networks you own or are authorized to test.

The exact GPIO wiring of a custom GhostChip PCB should be verified from its schematic before hardware connections.
